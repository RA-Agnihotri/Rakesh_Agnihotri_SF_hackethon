# Voice Input Feature — Demo Script (20–30s)

Every page in the Insurance AI Hub now supports voice input.

Tap the microphone icon, speak your question in any language, and the system transcribes it instantly using the Web Speech API.

If your prompt isn't in English, Snowflake Cortex AI Translate detects the language automatically and converts it to English — so the agent always understands your intent.

The translated text appears in the input field for review before you send it. A small indicator confirms the original language was detected and translated.

This works across all seven pages — from the AI Assistant to the Knowledge Hub, Data Explorer, and every specialized agent.

Voice in, intelligence out — in any language.
